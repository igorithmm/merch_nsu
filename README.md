# Мерч НГУ — учёт товара

Локальное приложение для продавца магазина университетского мерча: остатки по
моделям и размерам, продажа в один тап, приёмка партий, журнал движений и отчёты
для заказа новой партии.

Работает без интернета и без установки зависимостей — нужен только Python 3.9+.
Все данные лежат в одном файле `data/merch.db` рядом с программой.

## Запуск

```bash
python run.py
```

Откроется браузер со страницей `http://127.0.0.1:8765/`. Чтобы остановить —
`Ctrl+C` в окне терминала; данные сохраняются сразу после каждой операции.

Полезные ключи:

| Команда | Что делает |
| --- | --- |
| `python run.py --port 9000` | другой порт (если 8765 занят — свободный подберётся сам) |
| `python run.py --no-browser` | не открывать браузер |
| `python run.py --demo` | залить пример данных, чтобы посмотреть отчёты (работает только на пустой базе) |

## С чего начать

1. **Настройки → Продавцы** — добавьте имена тех, кто стоит за прилавком.
   Выбранное в шапке имя попадает в каждую строку журнала.
2. **Товары → Новая модель** — заведите модель: тип (толстовка), цвет
   (фиолетовая), принт (большая печать), цену и размерный ряд. Ряд выбирается
   кнопкой-пресетом (42–56, XS–XXL) или вписывается вручную через запятую.
3. **Остатки → режим «Приёмка» → «Принять партию»** — впишите, сколько штук
   пришло по каждому размеру. Это и есть первичный ввод остатков.
4. Переключитесь в режим **«Продажа»** и работайте.

## Три режима

Режим переключается в шапке и всегда подписан цветной полосой — чтобы не
перепутать «пришло» и «продано».

| Режим | Тап по числу | Кнопка − | Кнопка + |
| --- | --- | --- | --- |
| **Продажа** | продать 1 шт | продать 1 шт | оформить возврат |
| **Приёмка** | принять 1 шт | исправить приход | принять 1 шт |
| **Коррекция** | задать точный остаток | −1 (коррекция) | +1 (коррекция) |

В режиме приёмки на карточке есть кнопка «Принять партию» — ввод сразу по всем
размерам. В режиме коррекции — «Пересчитать всё» для инвентаризации модели.

Любую операцию можно отменить: кнопкой «Отменить» во всплывающем уведомлении
или «Откатить» в журнале. Откат возвращает остаток и оставляет обе записи в
журнале — история не переписывается.

## Подсветка остатков

* **красным** — 0 шт, закончилось;
* **жёлтым** — остаток не больше порога «мало на складе» (по умолчанию 2 шт,
  меняется в настройках);
* фильтр **«Заканчивается»** показывает только модели, где что-то на исходе.

Поиск работает мгновенно по названию, цвету и принту: «толстовка фиолет»
находит нужное. Фокус в поле поиска — клавиша `/`.

## Отчёты

Период задаётся кнопками (7/30/90 дней, год) или парой дат, можно ограничить
одним типом товара.

* **Что продаётся** — штуки, выручка, остаток и на сколько дней его хватит при
  текущем темпе.
* **Какие размеры вымываются первыми** — доля размера в продажах против его
  доли в остатке. Числовые и буквенные ряды считаются раздельно. Если синяя
  полоса заметно длиннее серой — этого размера в следующей партии нужно больше.
* **Пора заказывать** — позиции, которые продаются и вот-вот кончатся, с
  оценкой количества на месяц вперёд.
* **Лежит без движения** — товар с остатком, который не продавался дольше
  порога из настроек, и сколько денег в нём заморожено.

## Журнал

Все продажи, приёмки, возвраты и коррекции: когда, кто, что, сколько штук и на
какую сумму. Фильтры по периоду, типу операции, продавцу и поиск по тексту.
Кнопка «История» на карточке товара открывает журнал сразу по этой модели.

## Данные и бэкап

Вся база — один файл `data/merch.db`. Чтобы сделать копию, просто скопируйте
папку `data` (при остановленном приложении). Выгрузка в CSV для Excel —
на вкладках «Отчёты», «Журнал» и «Настройки».

## Как устроено

```
run.py            запуск: поднимает локальный сервер и открывает браузер
app/db.py         SQLite: схема, остатки, журнал движений
app/api.py        бизнес-логика: товары, операции, отчёты, экспорт
app/server.py     HTTP-сервер и JSON-API
app/demo.py       генератор примера данных
web/              интерфейс: index.html, style.css, app.js
```

Внешних библиотек нет — только стандартная библиотека Python и обычный
JavaScript в браузере.
